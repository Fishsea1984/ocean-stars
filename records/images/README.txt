====================================
  旅途记录 · 图片上传说明
====================================

【文件夹结构】

  images/
    ├── trip-01-jinmengshan/       ← 旅程1：晋蒙陕八日自驾
    │   ├── cover.jpg              ← 旅程封面图（记录卡片展示用）
    │   ├── day1/                  ← D1 启程 · 照片放这里
    │   ├── day2/                  ← D2 古韵 · 照片放这里
    │   ├── day3/                  ← D3 旷野 · 照片放这里
    │   ├── day4/                  ← D4 青城 · 照片放这里
    │   ├── day5/                  ← D5 大漠 · 照片放这里
    │   ├── day6/                  ← D6 文脉 · 照片放这里
    │   ├── day7/                  ← D7 初心 · 照片放这里
    │   └── day8/                  ← D8 归途 · 照片放这里
    │
    └── trip-02-xxx/               ← 旅程2（下次旅行时新建）
        ├── cover.jpg
        ├── day1/
        └── ...

【上传方法】

  方法一：宝塔面板（推荐）
    1. 登录宝塔面板 → 文件管理
    2. 找到网站目录 → records → images → trip-01-jinmengshan → day1
    3. 点击"上传"，选择当天的旅行照片
    4. 其他天数同理，上传到对应的 day2、day3... 文件夹

  方法二：FTP 上传
    1. 用 FileZilla 连接服务器
    2. 导航到 records/images/trip-01-jinmengshan/day1/
    3. 拖入照片即可

【图片建议】
  - 格式：JPG / PNG / WebP
  - 尺寸：宽度 800px 以上
  - 大小：单张不超过 2MB
  - 命名：建议用日期+序号，如 01.jpg、02.jpg

【封面图 cover.jpg】
  每个旅程文件夹中需要一张 cover.jpg 作为记录卡片的封面图。
  建议选择该旅程中最具代表性的一张照片，重命名为 cover.jpg 放入旅程文件夹根目录。

【新增旅程时】
  1. 在 images/ 下新建文件夹（如 trip-02-beijing/）
  2. 放入 cover.jpg 作为封面
  3. 按天创建 day1/、day2/ 等子文件夹
  4. 编辑 records/index.html 添加新的记录卡片
