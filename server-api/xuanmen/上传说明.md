# 玄门问道 · 云端存档 服务器部署说明

> 目标：让修行进度不再只存在浏览器里，而是保存在你的服务器上，换手机、换电脑也能接着修。

## 一、这套东西是什么

```
浏览器（xuanmen/index.html 里的云存档面板）
        │  存档码（16位以上字母数字，相当于钥匙）
        ▼
save.php（本文件，单文件接口，无需数据库）
        │  sha256(存档码).json
        ▼
saves/ 目录（每份存档一个文件，最大 512KB）
```

页面上的云存档面板会：
- 自动把游戏在本机写的存档**上传**到服务器（每 15 秒检查一次，有变化才传）
- 打开页面时自动从服务器**拉取**较新的存档（换设备时输入同一个存档码即可）

## 二、上传 3 个文件

把 `server-api/xuanmen/` 里的内容传到你服务器的网站目录下，比如：

```
网站根目录/xuanmen-save/
├── save.php
└── saves/.htaccess        （saves 目录会被自动创建，htaccess 是防下载用的）
```

用宝塔面板的话：文件管理 → 进入网站根目录 → 新建文件夹 `xuanmen-save` → 把 `save.php` 传进去即可。
`saves/` 目录不用手动建，接口第一次写入时会自动创建（权限 0755）。

## 三、验证

浏览器打开（把域名换成你的）：

```
https://www.yhtaoism.com/xuanmen-save/save.php?action=ping
```

看到 `{"ok":true,"service":"xuanmen-save","time":...}` 就说明部署成功。

## 四、⚠️ 必须 HTTPS（最重要的一步）

你的网站在 GitHub Pages 上是 **https**，如果存档接口是 **http**，浏览器会按「混合内容」规则
**直接拦截请求**，云存档完全不可用。所以必须给域名上 HTTPS：

- 宝塔面板 → 网站 → 设置 → **SSL** → Let's Encrypt → 勾选域名 → 申请（免费）→ 打开「强制HTTPS」
- 阿里云的话也可以在证书服务申请免费 DV 证书后绑定

上好证书后再访问 `https://域名/xuanmen-save/save.php?action=ping` 验证。

## 五、CORS（跨域许可）

默认 `save.php` 允许任意来源访问（`Access-Control-Allow-Origin: *`），个人存档接口没有 Cookie、
没有 CSRF 风险，这样最省事。

如果想收紧到只有你自己的站点能调，打开 `save.php` 顶部：

```php
$allowedOrigins = array(
    'https://你的用户名.github.io',
    'http://localhost:8000',
);
```

注意：一旦配置了白名单，白名单之外的来源（包括手机浏览器直接访问调试）会被拒绝。

## 六、页面上的存档服务器地址

页面默认指向 `https://www.yhtaoism.com/xuanmen-save/save.php`。
如果你的接口放在别的域名/路径，打开玄门问道页面，云存档面板最下面有「修改」按钮，
改成你的实际地址即可（浏览器会记住，只填一次）。

## 七、日常使用

1. 打开玄门问道页面 → 云存档面板 → 点 **生成新码**（自动上传一份当前存档）
2. **把生成的 20 位存档码抄下来**（它就是你的云存档钥匙，丢了别人也能读，所以别发给别人）
3. 以后正常玩，页面开着就会自动同步；也可以随时点「↑ 上传到服务器」手动存
4. 换设备：打开页面 → 输入同一个存档码 → 点「绑定 / 读取」→ 自动恢复到服务器上的进度

## 八、安全与容量说明

| 项目 | 数值 |
| --- | --- |
| 单份存档上限 | 512 KB（实际一份约 2~10 KB） |
| 存档总数上限 | 2000 份（防止被刷爆磁盘） |
| 写入限流 | 每 IP 每 5 分钟 60 次 |
| 读取限流 | 每 IP 每 5 分钟 300 次 |
| 文件名规则 | sha256(存档码)，无法通过猜测路径访问他人存档 |
| 存档目录 | saves/ 下 .htaccess 已禁止直接下载 |

存档码只有你自己知道 → 只有你能读写你的存档。**请勿把存档码发给别人**。
