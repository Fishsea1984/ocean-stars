## 玄门问道 云端存档（保存到服务器端）
- 用户选择：用**自己的服务器（PHP）**做存档后端。
- 服务器探测结论：IP `39.107.192.11` nginx 活着（200），但 `www.yhtaoism.com` 502、
  `/diary/api/list.php` 等全部 404 —— 老站点实际已下线/配置断；HTTPS 状态未知（本机代理 TLS 握手超时，无法判定）。
  ⚠️ 部署前必须给域名上 HTTPS（Let's Encrypt），否则 GitHub Pages(https) 调 http 接口会被浏览器按混合内容拦截。
- 服务端：`server-api/xuanmen/save.php`（单文件、无数据库）
  - GET `?action=ping` / `?action=load&key=` / POST `{key,data}`
  - 存档文件名 = sha256(存档码)（杜绝路径穿越）；单份 ≤512KB；总数 ≤2000；IP 限流 读300/写60 每5分钟；原子写入(rename)
  - `saves/.htaccess` 禁止直接下载；CORS 默认 `*`（无 Cookie 无 CSRF 风险），可改白名单
  - 本机无 PHP，用自写词法检查器校验了括号/字符串平衡（结果全部平衡）
- 客户端：`xuanmen/index.html` 顶部新增「☁️ 云存档」玻璃面板（生成新码 / 绑定读取 / 手动上传下载 / 自动同步开关 / 可改接口地址）
  - 原理：**不动游戏 bundle**，直接同步游戏自己的 localStorage 键 `xuanmen-wendao-save-v1`
  - 每 15s 检查本机存档变化→自动推送；打开页面自动拉取较新存档并 reload（sessionStorage `xm_pulled` 防循环）
  - 存档码 20 位（去混淆字符集），存 localStorage `xm_sync_key`；接口地址存 `xm_save_api`，默认 `https://www.yhtaoism.com/xuanmen-save/save.php`
  - 生成脚本 `build_xuanmen.py` 已加入 CLOUD_JS/面板，以后升级游戏重建页面不会丢
- **端到端验证**（用 Python 模拟同协议的 mock 服务器 + agent-browser 实测）：

  - 删掉本地存档（模拟换设备）→ reload → 自动恢复，道号一致 ✓
