## 玄门问道融入站点（新页面 xuanmen/index.html）
- 来源：桌面 `玄门问道-NAS部署包.zip`（单文件 React 应用，330KB，Vite 打包，存档在 localStorage `xuanmen-wendao-save-v1`）。
- 做法：**内联融入**而非 iframe。生成脚本 `.workbuddy/build_xuanmen.py`：提取 bundle（`<script type="module">`，255K 字符）
  与自带 CSS（35K 字符），CSS 全部**作用域化**到 `#xuanmen-root` 后注入新页面，避免污染站点全局样式。
- CSS 作用域化规则（`scope_css()`，可复用）：
  - 普通选择器 → `#xuanmen-root xxx`；`*` → 容器自身+`#xuanmen-root *`；`:root` 变量 → `#xuanmen-root`
  - `body{...}` → `#xuanmen-root{...}`；`html,body{height:100%}` 直接丢弃；`@import`（Google Fonts）丢弃（国内拖慢首屏）
  - `@media/@supports` 递归处理，`@keyframes/@font-face` 原样保留
- 页面结构照抄子页模板：站点 head + `css/style.css` + canvas 星空 + 导航 + 面包屑 + page-hero + 玻璃外框 `.xm-frame`
  包住 `<div id="xuanmen-root"><div id="root"></div></div>` + 页脚两行 + `js/main.js`。
- **导航调整**：`.workbuddy/add_nav_xuanmen.py` 在 21 个页面「首页」后插入「玄门问道」，最终顺序：
  首页 / 玄门问道 / 日记 / 记录 / 文章 / AI咨询 / 关于（脚本按各行实际缩进和 `../` 前缀自动生成）。
- 首页 features-grid（auto-fit 栅格）加了第 4 张卡「☯ 玄门问道」链接入口。
- 浏览器实测（agent-browser）：页面渲染正常、点击「立仙籍」进入游戏，资源栏/六板块/道心系统全部可用，存档写入 localStorage 成功。
- **测试坑**：站点 CSS 有 `html{scroll-behavior:smooth}`，Playwright 点击前自动滚动是平滑动画，坐标漂移导致点空；
  先 `scroll down` 再 `click` 即可。判断"是不是真坏了"的诀窍：用 `eval` 执行 `element.click()`（JS 点击），能触发就说明应用没问题。
- 测试工具：agent-browser CLI 装在 `C:\Users\Administrator\.workbuddy\binaries\node\versions\22.22.2-3\node_modules\agent-browser\bin\agent-browser-win32-x64.exe`，
  bash shim 的 `dirname/head/ls` 都缺失，要直接调 exe 并把 node 目录加进 PATH；batch 参数会被去引号，eval 里用 `String.fromCharCode` 代替字符串字面量。
- 升级游戏版本的方法：拿到新 index.html 后重跑 `build_xuanmen.py`（改一下 APP 路径指向新文件）即可重新生成。
- 冒烟测试：22 页全 200、0 死链、0 缺资源。xuanmen/index.html 330.6 KB（仓库总量 88→88.4 MB）。
