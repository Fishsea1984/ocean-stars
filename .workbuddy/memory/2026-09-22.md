# 2026-09-22 工作日志

## 网站整体安全加固（本轮主要工作）

用户提问：网站架构有无安全漏洞、如何加固。做了完整审计并落地修复。

### 审计结论（线上实测证据）
- **高危**：`diary/api/save.php / delete.php / upload.php` 完全无鉴权 → 线上 `delete.php` 实测返回 200，任何人可删除全部日记、图片、视频。这是此前数据被清空的根因。
- **高危**：`upload.php` 用客户端文件名取后缀（`pathinfo($file['name'])`）→ 可写入 `.php` 伪装文件，潜在 GetShell。
- **高危**：根目录 126MB 整站备份包 `blog.zgrecruit.com_20260916_214002.tar.gz` → 已移出到 `F:\ocean-stars-v2-backups\`。
- **中危**：`/diary/data/xxx.json` 可直接下载（实测 200）；`ai/api/test.php` 公开暴露 PHP 环境 + API Key 前6后4位；新闻页 `innerHTML` 注入 RSS → 存储型 XSS；AI 接口无限流；`tools/auth.js` 客户端认证可被绕过。
- **低危**：CORS 通配 `*`；RSS 抓取未校验证书、未防 XXE；缺安全响应头；`?force` 无节流。

### 已落地的代码改动
- 新增 `_sec/config.php`（盐+SHA256 口令哈希）、`_sec/auth.php`（统一 `require_admin()` / `require_post()`，HTTP Basic Auth）。
- 改写 `diary/api/save.php`、`delete.php`、`upload.php`：加鉴权、仅 POST、限长、媒体路径白名单、**后缀只由服务端 MIME 决定**、图片二次解码、文件名随机化。
- `diary/api/list.php`：移除通配 CORS，预留"读取也私有"的开关注释。
- `diary/index.html`：新增 401 友好提示（list/save/delete/upload 四处）。
- `ai/api/chat.php`：IP 限流（10 分钟 30 次）、角色白名单防提示词注入、单条限长、支持环境变量 `DEEPSEEK_API_KEY`。
- `ai/api/test.php`：需鉴权，且不再回显任何密钥片段。
- `news/api/fetch.php`：输出清洗防 XSS、链接仅允许 http(s)、`LIBXML_NONET` 防 XXE、校验证书、`?force` 节流 60 秒。
- 新增 `.htaccess` 兜底：`_sec/`、`diary/data/`、`diary/uploads/`。
