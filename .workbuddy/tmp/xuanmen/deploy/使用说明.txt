  玄门问道 · 群晖 NAS 部署说明
════════════════════════════════════════════════════════════

本部署包内含：
  html/index.html        网站本体（单文件版，约 330KB）
  docker-compose.yml     Docker 方式部署配置（方案 B 用）

────────────────────────────────────────────────────────────
 方案 A：Web Station（最简单，推荐新手）
────────────────────────────────────────────────────────────

1. 打开群晖 DSM 网页管理界面 → 套件中心
2. 搜索「Web Station」并安装（DSM 7 会自动连带安装 Apache/NGINX）
3. 打开 File Station，找到共享文件夹 web（安装 Web Station 后自动出现）
   ※ DSM 6 若无 web 文件夹，可手动创建一个名为 web 的共享文件夹
4. 把本包 html 文件夹里的 index.html 上传到 web 文件夹根目录
   （直接拖拽上传即可；不要上传整个 html 文件夹，只传里面的文件）
5. 浏览器访问：http://你的NAS内网IP/
   例如 http://192.168.1.10/ 即可开始修行

验证：看到「玄门问道」水墨首页即为部署成功。

────────────────────────────────────────────────────────────
 方案 B：Container Manager 容器部署（DSM 7.2+ 推荐）
────────────────────────────────────────────────────────────

特点：不占用 80 端口、与 Web Station 互不干扰、随 DSM 重启自动拉起。

1. 套件中心安装「Container Manager」（旧版 DSM 叫 Docker）
2. File Station 中在 docker 共享文件夹下新建子文件夹 xuanmen
   完整路径类似：/docker/xuanmen
3. 把本包 html 文件夹里的 index.html 上传到 /docker/xuanmen/html/
   （即先在 xuanmen 下建一个 html 子文件夹，再把 index.html 传进去）
4. 打开 Container Manager → 项目（Project）→ 新增
   - 项目名称：xuanmen
   - 路径：选择 /docker/xuanmen
   - 来源：选择「创建 docker-compose.yml」，把下方内容原样粘贴进去：

       services:
         xuanmen:
           image: nginx:alpine
           container_name: xuanmen-wendao
           restart: unless-stopped
           ports:
             - "8090:80"
           volumes:
             - ./html:/usr/share/nginx/html:ro

5. 点击下一步 → 完成，等待镜像拉取并启动
6. 浏览器访问：http://你的NAS内网IP:8090/

若提示防火墙拦截：控制面板 → 安全性 → 防火墙，放行 8090 端口
（默认 DSM 未启用防火墙规则时可跳过此步）。

【等价做法·图形界面建容器】（不想用 compose 的话）
  Container Manager → 容器 → 新增：
  - 映射端口：本地 8090 → 容器 80
  - 卷映射：/docker/xuanmen/html → /usr/share/nginx/html（只读）

────────────────────────────────────────────────────────────
 手机访问
────────────────────────────────────────────────────────────
手机连同一 Wi-Fi，浏览器访问 http://NAS内网IP:8090
（方案 A 则直接访问 http://NAS内网IP/）
页面已做移动端响应式适配，可直接游玩。

────────────────────────────────────────────────────────────
 可选：外网访问（出门在外也能挂机）
────────────────────────────────────────────────────────────
推荐「登录门户 + 反向代理」方案，不建议直接把端口暴露公网：

1. 控制面板 → 外部访问 → DDNS，注册一个群晖免费 DDNS 域名
   （如 xxx.synology.me，需路由器支持 UPnP 或手动做端口映射）
2. 控制面板 → 登录门户 → 高级 → 反向代理 → 新增：
   - 来源：HTTPS，端口任选（如 8443），主机名填 DDNS 域名
   - 目的地：HTTP，localhost:8090（方案 A 填 localhost:80）
3. 在同一页面「证书」里为 DDNS 域名申请 Let's Encrypt 免费证书
   并绑定到该反向代理规则，实现 HTTPS 加密访问
4. 强烈建议同时：
   - 控制面板 → 安全性 → 帐户开启两步验证
   - DSM 管理端口不暴露公网，仅暴露反向代理端口

安全提醒：游戏存档在浏览器本地（localStorage），
外网 HTTPS 访问是加密传输，别人无法读取你的修行进度。

────────────────────────────────────────────────────────────
 存档说明（重要）
────────────────────────────────────────────────────────────
· 存档保存在「浏览器」而非 NAS：换浏览器、换设备、清除
  浏览器缓存/Cookie 会丢失进度，请勿随意清理站点数据。
· 手机与电脑的进度各自独立（当前为单机版）。
· 同一台设备上方案 A 和方案 B 的存档也是分开的（不同地址）。
· 后续如推出多端账号互通版（服务器端存档），届时数据可迁移。

────────────────────────────────────────────────────────────
 常见问题
────────────────────────────────────────────────────────────
Q：页面空白 / 下载了文件而不是打开网页？
A：确认访问的是 http:// 开头且以 / 结尾（如 http://192.168.1.10:8090/），
   不要用 file:// 直接双击 NAS 上的文件——其实单文件版双击也能玩，
   但存档会绑定本地路径，建议统一走 NAS 地址访问。

Q：8090 端口被占用？
A：编辑 docker-compose.yml，把 "8090:80" 左边数字改成其他
   端口（如 18090:80），保存后在 Container Manager 里重启项目。

Q：更新游戏版本？
A：拿到新的 index.html，直接覆盖 NAS 上对应位置的旧文件即可，
   刷新浏览器（Ctrl+F5 强刷）生效。存档不受影响。
