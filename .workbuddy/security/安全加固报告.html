二、已完成的代码加固

新增：统一鉴权模块

  • _sec/auth.php——所有写操作的统一登录校验（HTTP Basic Auth，服务端比对，前端无法绕过）
  • _sec/config.php——口令的「盐 + SHA-256」哈希，不含明文

修改：日记接口

  • diary/api/save.php——加登录校验 / 仅接受 POST / 限长 / 媒体路径白名单
  • diary/api/delete.php——加登录校验 / 仅接受 POST / 删除时 basename 防路径穿越
  • diary/api/upload.php——加登录校验 / 后缀只由服务端识别的 MIME 决定 / 图片二次解码校验 / 文件名随机化
  • diary/api/list.php——移除通配 CORS（并预留"日记只给自己看"的开关）
  • diary/index.html——未登录时给出清晰提示，不再是莫名的"保存失败"

修改：其他接口

第 2 步：配置 Nginx 规则

宝塔 → 网站 → 你的站点 → 设置 → 配置文件，把 nginx-security.conf 里的规则整段粘贴进 server { } 内，保存并重载。

这一步解决：日记原始数据被直接下载、上传目录防执行、隐藏文件与备份包被下载、安全响应头缺失。

第 3 步：拿到并修改管理口令

我生成的初始口令存放在项目里的 .workbuddy/security/管理口令.txt，用户名是 admin。首次登录后建议立刻改成你自己的口令——方法是重新生成 _sec/config.php（改完告诉我，我帮你重新生成）。

⚠️ 上传时的关键注意事项（这次务必遵守）

你之前两次数据丢失，都是因为「删除旧目录 → 整体上传」。请改成：

  • 永远用覆盖文件，不要"删除目录再上传"；
